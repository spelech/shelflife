Add Plex Library Selection to admin settings

Administrators can now select which specific Plex libraries should be synced to Shelflife. This is useful for instances that contain multiple libraries (e.g. 4K vs 1080p, Kids vs Adult) where you only want specific collections managed or tracked in Shelflife. By default, all Movie and TV Show libraries will continue to be synced.
